# Arbitra Documentation

Welcome to the Arbitra docs. Arbitra is the policy enforcement layer for AI agents on Sui blockchain.

## What is Arbitra?

Arbitra sits between any AI agent and the economic actions it wants to take. It enforces rules the agent cannot override — at the Sui VM level.

**Tagline:** Give your agent a mandate. Not a leash.
